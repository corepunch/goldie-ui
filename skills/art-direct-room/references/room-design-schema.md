# Visual room design

Use this exact section order.

## Inputs

List the canonical source brief, visual references, and project-wide direction.

## Visual thesis

Describe the room's occupation, age, emotional tone, scale impression, and one
sentence that should govern every design decision.

## Reference decomposition

For each reference, record useful architecture, furniture, wall systems,
objects, palette, lighting, scale, and composition. Then state retained,
adapted, and rejected motifs.

## Categorized inventory

Use a table:

| Element | Class | Function | State | Zone | Visual priority | Evidence |
|---|---|---|---|---|---|---|

Class is `CANON`, `REFERENCE`, `INFERRED`, or `ATMOSPHERE`. Priority is
`hero`, `secondary`, or `support`.

## Spatial plan

Define room dimensions or proportions, architectural axes, ceiling treatment,
doors and windows, circulation, story-action clearances, and zones. Record
which objects are grouped physically and which require breathing space.

## Density plan

Specify all five passes:

1. Structural articulation
2. Hero furniture and silhouettes
3. Functional storage and wall occupation
4. Surface and floor clusters
5. Hardware and accents

For each pass, identify intended frame occupancy and vertical distribution.
Define occupancy as projected visible silhouette area or tonal-mass area in the
named camera, and state which measure the percentages describe.
Do not use a raw prop count as the sole density target.

## State variants

Map every canonical state to visible geometry, transforms, visibility, and
prop location changes.

## Lighting and palette

Name motivated sources, dominant direction, contrast, color families, and how
lighting reinforces hierarchy without hiding required objects.

## Camera coverage matrix

| Camera/story beat | Focal subject | Required canon | Reference-driven context | Depth planes | Text zone | Density risks |
|---|---|---|---|---|---|---|

Every hero element needs at least one camera where it reads clearly. Every
story camera needs a dominant mass, supporting masses, and intentional rest.
If no camera list is supplied, derive this matrix from the source brief's story
beats and label the cameras as proposed coverage.

## Implementation priorities

Order work by visual leverage: architectural and furniture silhouettes first,
then reusable storage systems, clusters, and accents. Identify reusable assets
and state-dependent assets.

## Unresolved decisions

List every noncanonical production choice that still affects layout, state
mechanics, camera coverage, or implementation. Assign the decision to art
direction, narrative adaptation, or implementation rather than hiding it in
the acceptance checklist.

## Acceptance checklist

- Canonical inventory and states remain intact.
- Major reference motifs have an explicit retain/adapt/reject decision.
- The room reads at thumbnail scale before small props are considered.
- Walls and ceiling are articulated enough to express scale and occupation.
- Hero furniture has functional construction and distinctive silhouette.
- Density appears in foreground, midground, background, and upper space.
- Unrelated objects preserve breathing space.
- Cameras cover the design without turning all negative space into clutter.
- Unknowns and subjective choices are documented.
