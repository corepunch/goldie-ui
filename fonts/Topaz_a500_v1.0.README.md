# Topaz_a500_v1.0.raw

Source: Multi Platform Amiga Fonts v1.02, `raw/Topaz_a500_v1.0.raw`
from the `rewtnull/amigafonts` archive:
https://github.com/rewtnull/amigafonts

This is the original Topaz Kickstart 1.x version, encoded as a headerless
8x16 bitmap: 256 glyphs, 16 bytes per glyph, one byte per row.

The upstream README states that the fonts are released under GPL-FE
(GPL with the font exception) and notes: "Topaz is (c) AmigaInc."
